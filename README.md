# beam-vmd

beam-vmd 是一套欧拉梁（Euler–Bernoulli）剪力、弯矩与挠度核算工具：给定跨度 L、抗弯刚度 EI、约束类型与梁上荷载，沿轴线输出剪力 V(x)、弯矩 M(x)、转角与挠度，并汇总支座反力；所有内力与位移共用同一套截面坐标与符号，并附带平衡、端弯矩、差分校核与刚度缩放等交叉校验。纯标准库实现，无第三方依赖，可离线构建。

## 支持的约束类型

- `simply`：简支（x=0 铰支、x=L 滚支），默认约束。
- `cantilever`：悬臂，固端在 x=0，x=L 自由。
- `fixed`：两端固支（both-ends-fixed）；JSON 亦可用别名 `both`。

荷载支持集中力 `points`（位置 `at`、带符号 `force`）与均布荷载 `distrib`（分段 `[from,to]`、集度 `q`）。

## 钉死的约定（README 中固定，代码与测试一致遵守）

- 坐标 x：从 0（左端）到 L（右端）。
- 荷载符号：**向下为正**。点力或均布集度取正值表示向下作用，负值表示向上。
- 支座反力在内部以「向下为正」求解，对外报告时转为「向上为正」（即反力向上为正）；固定端弯矩以「下凹为正 / 跨中受拉为正（sagging+）」报告。
- 弯矩 M(x)：**下凹为正**（sagging，梁底受拉）。
- 挠度：积分关系采用 `EI y'' = M`，其中 y 取**向上为正**；对外报告的挠度取该值的相反数，因此向下荷载产生**正**的（向下）挠度。报告转角 θ 为内部向上为正的值。
- 剪力 V(x) 为弯矩的导数，截面左侧荷载（点力取严格小于 x）累加起来，集中力处发生跳跃。

## 模型校验（非法输入一律返回 error）

- 跨度 L ≤ 0、EI ≤ 0；
- 集中力位置落在 [0, L] 之外；
- 均布段越界或 `from > to`；
- 未知约束类型。

以上任一情况，CLI 与 `POST /api/solve` 均返回明确错误，不会 panic。

## 交叉校验（已实现并测试）

1. 竖向平衡：外荷载竖向合力 + 支座竖向反力 = 0。
2. 简支时两端弯矩为 0。
3. 差分校核：(M_{i+1}−M_i)/Δx 逼近该段剪力 V；起点或内部含集中力的区间跳过（剪力不连续），改由第 4 项单独校验。
4. 集中力跳跃：跨过每个集中力位置，弯矩斜率跳变量等于该力（V 左/右极限之差 = −P）。
5. 挠度符号与荷载方向一致（向下荷载 → 正挠度）。
6. 增大 EI，同一荷载下 |y|_max 下降。
7. 闭式核对：简支/悬臂/固支的标准点载与满跨均布算例，采样 M 与 y 与解析式一致（钉死 EI y''=M 的符号与量级）。

## 构建 / 运行 / 测试

```text
go build ./...                       # 编译（纯标准库）
go test ./...                       # 单元测试（model / beam / sample）
go run . -solve example/simply.json # CLI：解算例并打印
go run . -http :8080                # Web 求解控制台
```

## Web 界面

`/` 提供静态页面：点击「加载示例」拉取内置简支跨中集中力算例，点击「计算」调用 `POST /api/solve`，展示支座反力与极值表，并用 SVG 绘制梁轴线和弯矩示意图（纵标取自 `/api/solve` 返回的 M(x) 采样，不写死任何抛物线）。

## API

- `POST /api/solve`：`{L, EI, support, points, distrib}` → 反力、V/M/y 采样、极值、交叉校验；非法模型返回 JSON 错误体 `{"error": "..."}`。
- `GET /api/example`：返回内置 `example/simply.json` 算例。
